# Week 6 — Decentralized Identity

A local classroom demonstration of decentralized identity
concepts using fictional identities and credentials.

## Scope

This project demonstrates:
- Local DID creation and inspection
- Fictional credential issuance
- Credential signature verification
- Credential tampering detection
- Later: trust and authorization decisions

## Safety

This repository must never contain:
- Private keys
- Wallet seed phrases
- Passwords
- Real personal information
- Production credentials
- .env files

All identities and claims used in this project are fictional classroom values.
